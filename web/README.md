# NeuroCare Web/PWA

این پوشه یک رابط وب واکنش‌گرا برای بیمار و پزشک است. پنل منشی وجود ندارد. رابط فقط داده واقعی API را نمایش می‌دهد و در نبود سرور، داده ساختگی را جایگزین نمی‌کند.

## استقرار رابط وب روی cPanel
1. محتوای پوشه `web/` را در پوشه ریشه یک زیردامنه اختصاصی (مثلاً `neurocare.mhsaffari.ir/public_html`) آپلود کنید.
2. فایل `config.js` را باز کنید و `API_BASE_URL` را به نشانی واقعی API با HTTPS تغییر دهید؛ نمونه: `https://api.example.ir/v1`.
3. برای زیردامنه گواهی SSL فعال کنید. PWA بدون HTTPS نصب‌پذیر نیست (به‌جز localhost).
4. در مرورگر، صفحه را باز کنید و «افزودن به صفحه اصلی» را بزنید.

## پیش‌نیاز سرور
این پوشه به‌تنهایی بک‌اند نیست. باید Node.js API و PostgreSQL را طبق فایل `../backend/README.md` مستقر کنید و مقدار `CORS_ORIGINS` را دقیقاً با origin رابط وب تنظیم کنید. اگر بسته هاست امکان Node.js و PostgreSQL نمی‌دهد، API باید روی یک سرور سازگار جداگانه اجرا شود.

## محدوده رابط فعلی
- بیمار: ثبت‌نام/ورود، وضعیت تأیید، درخواست نوبت، گزارش علائم/قبل از ویزیت، مشاهده برنامه درمان، داروها و یادداشت‌های قابل مشاهده.
- پزشک: مشاهده و تأیید بیماران، مدیریت درخواست نوبت، ثبت یادداشت بالینی، برنامه درمان و داروها، مشاهده گزارش‌های بیمار.
- داده‌ها فقط از API دریافت می‌شوند؛ هیچ بیمار نمونه‌ای داخل رابط وجود ندارد.

## مهم
جریان ورود فعلی سازگار با نسخه آزمایشی موبایل است و از کد ملی به‌عنوان اعتبار اولیه استفاده می‌کند. پیش از ورود بیمار واقعی، باید احراز هویت مستقل و امن (رمز مستقل یا کد یک‌بارمصرف)، بررسی امنیتی، قرارداد حفظ حریم خصوصی، پشتیبان‌گیری و ثبت ممیزی عملیاتی نهایی شوند.
