# جداسازی وب‌اپ بیمار و پنل پزشک

## مقصدهای مستقل
- بیمار: `https://app.mhsaffari.ir/` ← فقط محتوای پوشه `web/patient/`
- پزشک: `https://doctor-app.mhsaffari.ir/` ← فقط محتوای پوشه `web/doctor/`

در cPanel برای هر زیردامنه یک Document Root جدا بسازید. فایل‌های یک پوشه را فقط داخل Document Root همان زیردامنه آپلود کنید. پوشه پزشک را داخل Document Root بیمار کپی نکنید. بیمار نباید از وب‌اپ بیمار لینک یا منوی ورود پزشک ببیند؛ محافظ اصلی داده‌ها نیز کنترل نقش سمت Edge Function است.

## راه‌اندازی مشترک
1. پس از ایجاد پروژه Supabase، مقدار `API_BASE_URL` در فایل `config.js` هر دو پوشه را به `https://<PROJECT-REF>.supabase.co/functions/v1/neurocare-api/v1` تغییر دهید.
2. `APP_ROLE` را تغییر ندهید: پوشه بیمار باید `patient` و پوشه پزشک باید `doctor` باقی بماند.
3. دامنه‌ها باید HTTPS معتبر داشته باشند.
4. فهرست Originهای مجاز در Edge Function باید دقیقاً با دامنه‌های فوق یکی باشد.

## امنیت و محدودیت‌ها
- رابط بیمار و پزشک از دو Document Root و دو Origin مستقل استفاده می‌کنند.
- جداول عمومی مستقیم برای `anon` و `authenticated` دسترسی ندارند؛ Edge Function با کنترل نقش به داده دسترسی می‌یابد.
- هیچ داده پرونده‌ای در Service Worker یا Cache آفلاین ذخیره نمی‌شود.
- ثبت‌نام فعلی به‌صورت اولیه کد ملی را به عنوان رمز موقت در نظر می‌گیرد؛ بیمار قبل از باز شدن بخش‌های دیگر باید رمز مستقل حداقل ۱۲ نویسه‌ای تعیین کند.
- این سامانه تا پایان تست امنیتی، تنظیم HTTPS، پشتیبان‌گیری و تأیید workflow نباید با داده واقعی بیمار استفاده شود.
