# Saffari NeuroCare

سامانه همراه بیماران دکتر صفاری — نسخه وب/PWA، اپ اندروید بیمار و پزشک، و API مشترک.

**این مخزن هنوز به‌تنهایی سرویس آنلاین نیست.** ابتدا راهنمای [استقرار](backend/README.md) را بخوانید. پیش از استفاده با اطلاعات واقعی بیمار، احراز هویت مستقل، TLS، پشتیبان‌گیری و ممیزی امنیتی باید تکمیل شود.

- [راهنمای API و PostgreSQL](backend/README.md)
